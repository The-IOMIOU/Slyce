# Parity baseline — 2026-11-16

**Slyce:** commit `241eaae5e5` (OrcaSlicer 2.5.1 + Bambu presets from Bambu Studio 02.09.01.70, loop
direction and monotonic-line top fill ported), Release build, Windows 11, MSVC 19.51.
**Reference:** Bambu Studio 02.09.01.70, official Windows zip from `bambulab/BambuStudio` releases.
**Cases:** `tools/gcode_parity/cases/p1s_*.json`, `p2s_*.json` — PLA Basic, 0.20 mm Standard, 0.4 mm
nozzle; generated models (20 mm cube, 20 mm square tube with a 12 mm hole, overhang ramp).
**Presets:** flattened (`inherits` + `include` merged) before both CLIs, see decision 0008.

```
python -m gcode_parity.run --reference <bambu-studio.exe> --reference-profiles <bambu>/resources/profiles \
    --candidate build/src/Release/orca-slicer.exe --candidate-profiles resources/profiles --cases <p1s+p2s cases>
```

## Differences found, and their cause

| # | Difference | Cause | Status |
| --- | --- | --- | --- |
| 1 | 26 shared settings resolve differently with identical presets (e.g. `precise_outer_wall` 0 vs 1, `internal_solid_infill_pattern` rectilinear vs monotonic, `seam_gap` 15 % vs 10 %) | Bambu's presets leave them unset and the two apps' built-in defaults differ | Fixed for the 12 with the same meaning: `tools/bbl_profiles/bambu_default_overlay.json` |
| 2 | Outer wall 0.043 mm further in, ~0.5 % less extrusion per layer | `precise_outer_wall` default (#1) | Fixed by #1, to re-measure |
| 3 | Wipe: Slyce retracts 0.5 mm first and 0.3 mm during the wipe; Bambu 0.76 mm during, 0.04 mm after | OrcaSlicer caps wipe retraction by `retraction_speed` | Ported Bambu's split on Bambu printers, to re-measure |
| 4 | Layer-change lift 0.2 mm higher (`G3 Z1.6` vs `Z1.4`) | OrcaSlicer moves the Z position to the new layer before the lift | Ported (pending lift reduced by the layer step), to re-measure |
| 5 | No `M204 S250` short-travel accelerations (Bambu: ~100 per print) | `travel_short_distance_acceleration` missing | Ported, to re-measure |
| 6 | No `M1003 S0` at the end; no spiral lift at the end | Power-loss recovery default "printer configuration"; plain final retract | Ported, to re-measure |
| 7 | Bed-mesh probe box 2 mm larger each side (`G29 … X116 Y116 I24 J24` vs `X118 Y118 I20 J20`) | First-layer hull includes an auto-brim area in Slyce's brim code | Open. Larger box is safe (probes more) |
| 8 | Square tube: −38 % sparse infill, +15 % internal solid, no floating vertical shell | Narrow-region handling diverged (`split_solid_surface`; no `stFloatingVerticalShell`) | Open, large port |
| 9 | P2S estimated time +22–26 % | Time estimator | Open, not yet investigated |
| 10 | Fan-off commands just before instead of just after the first layer marker; P2S 2 extra | Different placement of the start-of-print fan reset | Open, cosmetic |
| 11 | Labels "Internal Bridge" (Slyce) vs "Bridge" (Bambu) | Naming only | Open, cosmetic |
